## 一、这一版能做什么

1. 批量导入身份证照片（本地处理，图片不出机器，无任何上传）
2. 自动找出卡片四角并做透视矫正 → 输出 1011×638 带圆角（R≈35px）
3. 自动判横竖、自动转正（0°/90°/180°/270° 均可手调）
4. 手动兜底：拖四角、方向微调（1px/5px/20px 步长）、整图模式
5. 打分台：逐张打标签、写备注、存基准、导出 corrections.json 供算法侧分析
6. 归一化导出：`序号_原文件名.png`，报告含 `key/no/gold/steps/diag/engine`

## 二、双检测引擎

| 引擎 | 实现 | 体积 | 说明 |
|---|---|---|---|
| 经典 | 直方图/低饱和掩膜 → 连通域 → 凸包 → 最小外接矩形 → 按 1.585 生成候选 → 打分 → 收边 → 全分辨率精修 | 0 | 纯几何启发式，无外部依赖 |
| ML | DocCornerNet LEAN（ONNX Runtime Web，WASM） | 模型 1.9MB + 运行时 1.5MB | 224×224 直接拉伸输入，输出 4 角 + 置信 |
| 整图即卡 | 长宽比偏差 <4% 且外环无背景色 → 判定整图就是卡 | 0 | 不跑模型，直接整图 + 圆角 |

### 引擎选择规则
- 右上按钮切换，状态存 localStorage；切换时**自动清空旧标签/备注/判定**（基准保留）
- ML 未检出 → 自动回退经典，徽标显示「ML→经典」
- 整图即卡命中 → 徽标显示蓝色「整图即卡」，跳过检测

## 五、踩过的坑（改代码前必读）

1. **`assetBaseUrl` 必须是绝对 URL**。给 `'./ml/'` 会被 ORT 以 mlDetector 自身目录为基准再拼一次，请求变成 `/ml/ml/ort-wasm-simd-threaded.mjs` → 404。
2. **指标必须用像素坐标算**。把归一化四角传给按像素的 `geom()`，会让面积变 0%、比例偏差变 0.394，并连锁把横竖判错、输出图切错方向。
3. **refineQuad 调用点必须排除 ML 与整图**：`r.engine!=="ml" && r.engine!=="whole"`，否则模型原始框/整图框会被精修破坏（整图会被咬掉一圈）。
4. **`is_vertical` 必须在 refine 之后重算**（`vertOf()`），否则竖卡输出侧躺。
5. **自动收紧（tightenQuad）默认关闭**。无脑向内收会 20/20 掉到 15/20：卡面内文字/花纹梯度比卡边强。`?tight=1` 可开。
6. **分享站点子资源 403 是正常现象**。网关要 sharecode 换 HttpOnly cookie，curl 直取 `/ml/*` 必 403，浏览器内正常。别误判部署失败。
7. **标签按文件名存 localStorage 且跨轮继承**。「全部重跑」只清框不清标签，换引擎才清。旧标签会污染报告。
8. **`verdict=ok` 会自动存基准**，存的是模型自己的框，`corner_shift` 全 0。所以「ok 数」是接受率，不是精度，不能当 IoU 用。
9. 4K 图必须先降到 ≤1800px 再送模型，否则 OOM；页面把图缩到 1800px 后 ML 分略低于 Python 原图版（0.928 vs 0.937）。
