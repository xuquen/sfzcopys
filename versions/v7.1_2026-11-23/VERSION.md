# v7.1 · 180° 倒置漏纠 + 面别判反（2026-11-23）

基线 v7（md5 `0a1bbda16b60120e8b132696cecf09d0`，1622 行）。
本版 md5 `ffbb594b8aea60aecafb51b718a37312`，1668 行（+46 行，全是判据与注释）。

## 作者报的现象

手机传两张卡（`微信图片_20261123091820_208`、`..._209`），A4 预览里**两张都上下颠倒**，
而且**面别全反了**：倒置的国徽面被标「人像面」，倒置的人像面被标「国徽面」。
面别跟着反是必然的 —— `sideOf()` 比的是左上/右下象限墨迹，图一转 180°，两个象限正好互换。

## 三个真 bug

### ① warpCanvas 输出带一条纯黑边（源头）
```js
const qpx = quad.map(p => [p[0]*sw, p[1]*sh]);     // 错
```
归一化坐标 1.0 乘 `sw` 得到 `sw`，而有效最大索引是 `sw-1`；
采样条件又写成 `sx<sw-1`，于是**最后一行、最后一列永远采样不到，被填成 0,0,0**。
实测 y=637 / x=1010 的中点像素确实全是黑。

危害不只是难看：`darkRowY()` 的「最强暗行」被这条黑边直接吸到画布底端（`ry=1.00`），
朝向判据因此失效。改成 `p[0]*(sw-1)`，并把采样条件放宽到 `sx<=sw-1`、
`x0=min(sw-2, floor(sx))` 做邻近复制。

### ② 朝向判据在国徽面上根本不成立（主因）
原判据只有 `segScore`（底部暗段数 − 顶部暗段数），阈值 12。
把 20 张正立卡退化成「微信级压缩」（缩到 340px 宽再放大 + 高斯模糊 + q55 + 偏蓝）后：

| | 正立 | 倒置 |
|---|---|---|
| 人像面（10 张） | +12 ~ +24 | −12 ~ −24 |
| 国徽面（10 张） | **+1 ~ +11** | **−1 ~ −11** |

国徽面底部只有「签发机关 / 有效期限」两行，段数本来就少，一糊就全挤进阈值内 → 漏转。
作者那张国徽面正是如此。

### ③ 阈值 12 又把清晰国徽面推给了不可靠判据
清晰图上 `06_B` / `08_B` 的 segScore 是 +9 / +11，差一点够不到 12；
退回「暗行位置」判据后又判反 —— 因为**清晰图顶部「居民身份证」粗体大字暗像素更多**。

## 新判据

```js
darkRowY(cv)  // 全卡"暗像素最多的一行"的 y 位置，跳过最外 2 行
orientScore() // |segScore|>=8 用 segScore，否则用 darkRowY 的 0.5 偏移量
```
两个判据的强项正好互补，谁强用谁：

| | segScore | darkRowY |
|---|---|---|
| 清晰图 | 人像面强、国徽面弱 | **会被顶部大字骗** |
| 退化图 | 人像面仍强、国徽面失效 | **正立 0.73~0.88 / 倒置 0.12~0.27，余量 0.23** |

阈值取 8 而不是 12，是为了让国徽面那批「+9~+11 的微弱但符号正确」的信号留在 segScore 这边。

## 面别判据

原判据只看左上 vs 右下的暗占比差，阈值 0.06，差值 0.02~0.06 的留成待定（作者那张正好 0.022）。
四象限重测后发现**左上象限本身就够分**：

| | 左上暗占比 |
|---|---|
| 国徽面（10 张） | 0.255 ~ 0.315（国徽是深色圆块） |
| 人像面（10 张） | 0.046 ~ 0.085（只有"姓名"几行细字） |
| 作者那两张 | 0.158 / 0.071 |

新增两条前置判据：`a>0.13` → 国徽面；`a<0.10 && b-a>0.08` → 人像面；都不满足才走老的 0.06 兜底。

顺带排除了「国徽红色重心」这条路：人像面左上也有 0.08~0.12 的红色（背景偏色），
和国徽面的 0.10 完全分不开，与 v4 那次的结论一致。

| 用例 | 结果 |

| 作者报的那两张 → 完整 UI → PDF | 都转正，判「国徽面 / 人像面」，PDF 232KB，0 JS 错 |

`rot` 分布：22 张 `rot=0`、4 张 `rot=3`（原图竖拍侧躺，走竖版分支转 90°）。

## 遗留

- `darkRowY` 全高扫描比原来只在两条窄带里扫贵约 5 倍；单卡 20~35ms，仍在可接受范围
- 两面自动配对仍需 OCR（国徽面无人名无号码）
- 银行卡被跳过时只靠 toast 报数
