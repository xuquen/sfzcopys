# v7.10 @ 2026-11-23

## 改动：保存文件名模板 + 联网 OCR（最小上传方案）

作者需求：保存文件名可在设置里组合标签、可乱序；默认「身份证-当前日期+时分秒」；
标签含 OCR 字段（姓名/身份证号/终止有效期/地址）、当前时间、固定手输内容、序号
（可设起始号，新人像 +1、同人正反面同号）；OCR 选联网识别，key 处带简要说明。
追加要求：**OCR 只传最小图片量**——模板里用了哪个标签就只截那个字段的区域上传。

### 文件名模板
- 设置弹层新增「保存文件名」：模板输入框 + 7 个标签芯片（点击在光标处插入）+
  固定文字 + 序号起始 + 实时预览；模板/固定文字/起始号存 localStorage
- `buildName()`：展开标签 → 删掉没识别出的空标签 → 收连字符/去首尾 → 清非法字符
- 默认 `身份证-{时间}`，{时间}=YYYYMMDD-HHMMSS；PDF/图片导出统一走 buildName

### 联网 OCR（百度通用文字识别 general_basic）
- **字段小图裁剪**（归一化框，5 人 10 面目视标定套准）：
  姓名 [0.165,0.070,0.640,0.235]、地址 [0.165,0.470,0.660,0.730]、证号 [0.320,0.775,0.940,0.950]（人像面）；
  有效期止 [0.300,0.780,0.920,0.950]（国徽面）。实测上传体 6.5~18.6KB base64，整卡要 150KB+
- `neededOcrFields(side)`：只对模板里出现的标签、且面别匹配的卡发起识别；一个字段一次调用
- 解析：姓名取第一条纯汉字行（防串行）；证号取最长 15~18 位数字串；地址去非汉字数字；
  有效期止取最后一个日期 → YYYYMMDD，「长期」特判
- **跨卡合并**：姓名等在人像面、有效期止在国徽面，`buildName` 合并所有卡的 ocr 字段
  （首修 v7.10 初版「只取第一张有 ocr 的卡」的 bug——字段分散时后面的丢）
- 面别手动切换时作废 ocr 并重新入队
- 开关默认关；开启需 confirm（说明只传字段小图）；顶栏徽章变橙色「联网OCR」；
  key 存本机 localStorage；token 缓存 localStorage 带过期
