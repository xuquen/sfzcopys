# v7.3 · 桌面端入口改成「扫描」（2026-11-23）

md5 `daef3844a4db1277ba524428b1745449` · 1763 行 · 80KB
基于 v7.2，只改入口与提示，**算法一行未动**。

## 为什么这么改

浏览器无法访问扫描仪。扫描仪走 TWAIN / WIA / ICA / SANE 这类**系统驱动协议**，
而 NPAPI 与 ActiveX 早已被所有主流浏览器移除（Chrome 2015、Firefox 2017、IE 2022 退役）。
商用方案（Dynamic Web TWAIN 等）无一例外是「页面里的 JS SDK + 本机常驻服务」两段式，
要安装组件、要商业授权。纯静态页面做不到。

而 v7 之前桌面端点「拍照」是这样：`capture` 属性被浏览器忽略，
**静默退化成文件选择框**。用户只会觉得「点了拍照怎么弹选文件」。

所以桌面端把入口改成用户实际会做的动作：**扫描**（选扫描仪导出的图片）。
真正的设备接入（`getUserMedia` 取景）只对有 UVC 摄像头/高拍仪的场景有意义，
本次按作者决定不做。

## 改动

| | 移动端 | 桌面端 |
|---|---|---|
| 主按钮 | 拍照（`capture=environment`） | **扫描**（多选文件） |
| 次按钮 | 相册 | **图片** |
| 主按钮点击 | `#cam` | `#file` |
| 首屏提示 | 拍摄：卡放平、占满画面、避开反光 | **扫描件：让扫描仪输出 JPG/PNG（300dpi、卡摆正），PDF/TIFF 网页读不了** |
| 预览空态 | 人像面 + 国徽面各拍一张 | 人像面 + 国徽面各扫一张 |
| 卡片区空态 | 拍一张卡面，或从相册选 | 扫一张卡面，或从图片导入 |

判定用 `IS_IPAD || /android|iphone|ipod|mobile|harmonyos/`。
iPad 的 UA 伪装成 `Macintosh`，必须靠 `navigator.maxTouchPoints > 1` 才能认出来。

## 顺带修掉的哑提示

`addFiles` 原来把非 `image/*` 一律回一句「没有可用的图片」——
而**扫描仪默认常输出 PDF/TIFF**，iPhone 传电脑常是 HEIC，这三种浏览器都解不了。
用户只会反复重试，不知道是格式问题。现在分情况说：

- `application/pdf` → 「PDF 读不了：让扫描仪输出 JPG/PNG，或先截图再导入」
- `image/tiff` → 「TIFF 浏览器不支持：扫描仪里把格式改成 JPG/PNG」
- `image/heic` → 「HEIC 读不了：导出时选「兼容性最佳」，或先截图」

## 验证

**合成扫描件四种**（300dpi A4 白底 + 轻微倾斜 + 扫描噪点）：

| 样本 | 结果 |
|---|---|
| 只扫卡片（人像面，歪 0.8°） | 1 张卡，人像面，1011×638，151ms |
| 只扫卡片（国徽面，歪 −0.6°） | 1 张卡，国徽面，1011×638，77ms |
| A4 整页居中（歪 1.5°，卡占宽 41%） | 1 张卡，人像面，1011×638，150ms |
| A4 整页偏上（歪 −2.0°） | 1 张卡，国徽面，1011×638，120ms |

A4 整页那种最值得关注：卡只占画面 41% 宽，模型仍能精准框住卡边（不是框整页）。

**端到端**：
- 桌面 1280×900：`扫描 / 图片 / 粘贴`，tip 底部 795 < footer 顶部 831（未遮挡）；
  点「扫描」打开多选文件框（`multiple=true`）；2 张扫描件 → 2/2、面别对、PDF 210.0×297.0mm / 384KB
- 手机 iPhone UA：`拍照 / 相册 / 粘贴`，`capture=environment`，点「拍照」走单选；
  `#cam` 一张 + `#file` 一张 → 2/2、面别对、PDF 384KB
- 三种无解格式的提示文案实测全部命中；无 JS 错误

## 遗留

- 平板扫描仪仍无法直连，只能走「厂商软件导出 → 这里导入」，这是浏览器边界，不是实现问题
- 桌面端没有摄像头取景（按作者决定不做）。若日后要接高拍仪（UVC），加
  `getUserMedia` + `enumerateDevices` 设备下拉 + `ImageCapture` 抓静帧即可，路径已通
- 600dpi 扫 A4 会被 `MAXDIM=1800` 缩到卡只有 734px 再上采样回 1011，会变软；
  tip 里已写 300dpi
