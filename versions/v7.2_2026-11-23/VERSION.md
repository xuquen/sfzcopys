## 自动白平衡

「选项」区新增「自动白平衡」开关，**默认打开**，可关回原色。

### 估法：亮部灰世界（不是全图灰世界，也不是低饱和均值）
第一版按「剔除高饱和像素后估通道增益」写，实测有两个硬伤：

1. **偏色越重越失效**：饱和度阈值 `(max-min)/max > 0.32` 会把偏色图的像素全排除。
   人为暖偏 16% 的图上低饱和像素只剩 **2.3%**，低于 6% 门槛 → 直接放弃校正。
   逻辑是反的：最该校正的时候它跳过了。
2. **±12% 限幅不够**：国徽面暖偏图 Rb 只能从 1.494 拉到 1.185，仍明显偏黄。

改成：**只拿「亮度前 20%」的像素做灰世界**。身份证卡面 55~65% 是白底，白底就是画面最亮的部分，
所以亮部≈白底；国徽/人像/印章全在暗端，压根不进统计。亮部占比由白底面积保证，不受偏色影响。

```
亮度 = (77R + 150G + 29B) >> 8
thr  = 亮度直方图的 P80
mean = 亮度 ≥ thr 的像素的三通道均值
gain = clamp(mean均值 / mean_c, 1±0.20)
```

限幅放宽到 **±20%**。放宽是安全的：中性图算出的增益到不了边界，实测合成中性图 gain 全在 2% 内 → 返回 null，一份副本都不生成。

### 实测

| 样本 | 白底 Rb 前 | 后 |
|---|---|---|
| 合成中性（白底 236,236,236） | 1.000 | **不处理**（cvWb=null） |
| 暖偏 16% / 冷偏 20%（人像面） | 1.664 / 0.886 | 1.187 / 1.052 |
| 暖偏（国徽面） | 1.494 | 1.093 |
| 真实手机图 17 张 | 0.60~0.97 | 15 张被处理，向 0.85~0.93 收敛 |

红块（模拟国徽/印章）与白底的比值：前 0.909 → 后 0.908 —— **完全保持**。
白平衡是乘全局通道增益的线性变换，只改色温，不改任意两区域的相对色差，所以国徽不会变灰。
视觉验收图见 `out_v7/11_白平衡开关对比.jpg`。

### 实现要点
- `wbCopy(src)` 返回**新 canvas**，`null` 表示不需要校正
- `c.cv` 永远是原始像素（朝向/面别判据都在它上面算过）；`c.cvWb` 是可选的衍生
- `eff(c)` 按 `WB` 开关二选一，`paintSheet` / 缩略图 / 手动转 180° 全走它
- **开关切换不影响判据**，只换一份像素去画 → 切开关零延迟，也不用重跑检测
- 手动 `↻` 转 180° 时 `cv` 和 `cvWb` 必须一起转，否则一按开关就转回去

## 顺手修的：180° 纠正（继承 v7.1）

作者报的「两张卡都上下颠倒、面别也反」在 v7.1 已修，但**一直没部署**，线上还是 v7。
三个根因：`warpCanvas` 输出带纯黑底边（归一化 1.0 乘成 `sw` 而非 `sw-1`）、
`segScore` 在国徽面上退化后只剩 ±11（阈值 12 够不到）、阈值 12 又把清晰国徽面推给不可靠的暗行判据。
v7.1 引入 `darkRowY` 互补判据（阈值降到 8）+ 面别改左上象限主导，160 组方向回归全对。
