## 1:1 是怎么落地的

300 dpi 下 A4 = 2480×3508，85.6×54 mm = **1011×638** ——
和 `warpCanvas()` 的输出尺寸完全一致。所以拼版是**原像素贴图，零重采样**：

| 项 | 实测 |
|---|---|
| 整页 | 2480×3508 px |
| 卡面 | 1011×638 px = 85.6×54.02 mm |
| 两卡间隙 | 118 px = 9.99 mm（设 10 mm） |
| 水平留白 | 735 / 734 px（奇数宽度舍入 1px） |
| 垂直留白 | 上下各 1057 px（关于页心中线对称） |
| PDF MediaBox | 595.28×841.89 pt = 210.0×297.0 mm |
| 打印 CSS 下 img | 794×1123 px = 210×297 mm @96dpi |

## 新增判据：空白卡面（std < 12）

模型对**任何**图都会输出四个角，纯色/渐变图上照样"自信"地框一个，卡形门控挡不住。
实测：真实卡面（26 张，含银行卡）灰度 std `31.72~52.40`，纯色/渐变/噪点图 `0~4.63`，
中间空档极大 → 阈值取 **12**，两边各留 2.6 倍余量。
验证：纯色渐变图被拒（提示"这张几乎没内容"），8 张真实证件零误杀。

## 坑

1. **CDN 被墙** → jsPDF 必须自托管（`lib/jspdf.umd.min.js`，365 KB，v2.5.2）。
2. **空仓库/首屏布局**：A4 预览在 390 宽手机上占 512px，把"添加照片"顶出首屏。
   改成 `width: min(100%, calc((100svh - 288px) * 210 / 297))` 反算宽度，现在 266×376。
3. **`.tip` 不能用 flex**：文本节点和 `<b>` 都成了 flex item，`85.6 × 54 mm` 被拆两行。
4. **同图多卡与"一页 2 个位置"冲突**：拆出来的银行卡会挤掉国徽面的位置 →
   银行卡默认跳过。
5. **打印验不能用 `emulateMedia('print')` + 截图**：210mm=794px 超出手机视口，
   截到的是左上角一块白。要用 `page.pdf({preferCSSPageSize:true})` 走真打印管线。
6. **fullPage 截图里的 fixed footer 会乱入中部**，是截图假象，别据此改布局。
