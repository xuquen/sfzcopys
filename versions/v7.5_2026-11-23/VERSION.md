# v7.5 · 去阴影 + 白底增强（2026-11-23）

md5 `e56ca0e37897c29fae158611641ea2ee` · 2035 行 · 92KB

两项都是像素后处理，**检测/裁切/转正/面别判据一行未动**。
新增开关「去阴影」（默认开），「高对比度」的算法整个换掉。

## 一、去阴影（新增，默认开）

作者实拍反馈：拍照时阴影叠到卡面上，而且不均匀。

**做法 = 平场校正**（扫描仪与扫描类 App 消除光照不均的标准解法）：
阴影是乘性的 —— 像素 = 卡面反射率 × 该处光照。所以估出「这一处本该多白」再除掉即可。

```
W  = 局部纸白 = boxMean(Y⁶, 41)^(1/6) 再 smooth      // L6 范数≈滑动最大值，但不吃孤立反光点
out = 原图 × (255 / W)                               // 三通道同一增益
```

- 窗口 = 卡宽/25（1011 宽 → 41px）：比字大得多、比阴影小得多，正好只留下光照
- 三通道同增益 → **色相一点不动**：国徽还是红、肤色还是肤色、黑衣服还是黑
- 增益限幅 [0.55, 2.2]，防止某处纸白估得极低时把噪点放大到爆
- 本来就很匀的扫描件：`W≈255`、增益≈1，且未变动像素超过 98% 时直接返回 null（省一份内存）

实测（作者样张，卡裁出放大到 1011 宽）：人像面亮度 **153 → 238**、国徽面 **164 → 240**。

## 二、白底增强（原「高对比度」，算法整个换掉）

旧的 levels 全局拉伸 + 低饱和去色：白底不够白，深浅不一的卡效果差异大。

新做法三步：

1. **局部纸白归一化** `Yn = Y×255/W` —— 每处底纹都归到纸白，浅卡深卡一致
2. **硬阈值漂白**：`Yn` 超过 235 就混向纯白（去色度 + 提亮一次完成）
3. **版式先验保护人像**（仅人像面）：人像位置是固定的（实测 5 张都在 x 0.56~0.94、y 0.15~0.90），
   在框内抠出人像本体（比框内纸白暗 22 级、或明显彩色 → 大核填洞 → 羽化），
   **人像本体一个像素不动**，人像周围的底纹照样漂白 —— 所以看不到方框边

走过的弯路（都实测过，别再回头）：
- 只做 levels 全局拉伸 → 人像高光跟着白
- 只按饱和度去色 → **底纹与人像饱和度区间完全重叠**（底纹 P50 0.211 / 人像 0.179），任何阈值都同时命中
- Sauvola 局部阈值 → 「底纹浅+文字也浅」的卡上 t 落到 0.66m，浅笔画被推掉（05 号字形残缺）
- 保护框设成「整框不动」→ 人像周围留一圈黄底方块

实测（10 面）：底色 214~239 → **250.5~254.9**；文字/国徽位移 **0.00~0.18**；
人像色相 R−B **60.7→60.7 / 62.9→62.9 / 28.3→28.3 / 35.6→35.6**（零变化）。

## 三、像素管线

`eff(c)` 从三级扩到四级，顺序不能反：

```
cv → sh(去阴影) → cvWb(白平衡) → hc(白底增强)
```

先除光照再做白平衡（亮部灰世界的估计才准），漂白放最后（它要按纸白归一化）。
每级都记「我是在哪一份上游算的」（`shDone` / `wbFor` / `hcFor` / `hcSide`），
上游一换自动重算；切面别会让 hc 重算（guard 依赖面别）。

`wbCopy` 从「导入时算一次」改成懒算 —— 因为它的上游现在是 sh 的输出，不是原始 cv。

## 五、已知问题（本次未修，属上游）

白底增强把内部推白之后这圈脏边就更显眼。v7.4 同样存在，不是本次引入。
修法在上游（warp 后对四边做 2px 边缘克隆），卡内四周有 2~3mm 白边，克隆是安全的。
