# sfzcopys · 身份证打印前处理

把手机随手拍的身份证照片，自动**找框 → 矫正 → 裁切 → 摆正**，输出可直接送进打印机/排版软件的
`1011 × 638` 标准图。纯浏览器运行，**照片不出本机**。

> 中国第二代居民身份证卡面是固定比例 85.6 × 54 mm（≈ 1.585），
> 本项目所有几何判据都围绕这个比例建立。

---

## 它解决什么

手工把翻拍的身份证拉正、裁齐，一张要半分钟，还容易歪。这个工具做四件事：

| | 说明 |
|---|---|
| **找框** | 画面里有桌面、手指、阴影、别的卡片，也能定位到卡的四角 |
| **矫正** | 单应变换把透视变形拉回正矩形，不是简单外接框 |
| **裁切** | 输出固定 `1011×638`，等比填充（不拉伸压扁） |
| **摆正** | 侧躺 90° 的自动转正；同框有银行卡/社保卡时拆开并折叠 |

输出带 `R≈35px` 圆角与白边，可直接拼版打印。

---

## 快速开始

`site/index.html` 是**单文件**应用，但用了 ES Module 动态加载模型，
`file://` 直开会被浏览器 CORS 拦掉，必须走 HTTP：

```bash
cd site
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

拖入照片即可。右上角可切引擎（默认 ML）。

部署到任意静态托管也行（Nginx / Pages / OSS 都行），只要 `site/` 整目录上传、
保证 `ml/` 与 `index.html` 同级。

## 两种检测引擎

默认 ML，可在页面右上角切换，选择记在 localStorage。

### ML 引擎（推荐）

`ml/doccornernet_lean.ort`（1.9 MB），ONNX Runtime Web 跑在 WASM 上。
输入 `224×224` RGB，输出四个角的归一化坐标 + 置信度。

两段式：

1. **整图推理** → 若宽高比不像卡（`|ln(AR/1.585)| > 0.06`），按「整宽 × 55% / 62% 高」三档滑窗再推；
2. 候选过卡形门控 + IoU 去重 → 每个候选外扩 7% 再推一次精修，只接受"更像卡"的结果。

这第二步是拆同框多卡的关键：**单文档模型遇到两张同尺寸矩形时，倾向输出跨两张的并集，
而且置信度照样是 1.000** —— 分数完全识别不出这个错误，只能靠几何门控兜住。

### 经典引擎（零依赖兜底）

纯 JS 几何启发式，不需要任何模型文件：

灰度直方图百分位掩膜 + 低饱和高亮掩膜 → 连通域 BFS → 凸包 → 最小外接矩形 →
按 1.585 生成候选 → 多维打分（边缘支撑、内点率、面积、比例）→ 收边。

ML 加载失败或失手时自动回落到这里。

### 整图即卡

卡把整幅画面拍满时（比例对得上、四周没有背景环带），直接整图输出，不跑检测。

## 实测成绩

20 张自建基准，对人工标注 gold 算 IoU（角点四边形的交并比）：

| 引擎 | IoU ≥ 0.9 | 平均 IoU |
|---|---|---|
| **ML + 整图即卡** | **20 / 20** | **0.957** |
| ML（无整图规则） | 18 / 20 | 0.928 |
| 经典引擎 | 10 / 20 | 0.826 |

另有一批更硬的样本（20 张 = 10 人 × 2 面，每张还躺着另一张银行卡，4 张整体转了 90°）：
20 个文件拆出 26 张卡，**全部框正**，比例偏差 ≤ 0.015，4 张侧躺全部转正。

## 几个不显眼但很关键的细节

- **指标一律用像素坐标算，算完才归一化**。先用归一化坐标算面积/比例，遇到非正方形图会直接算错。
- **方向判定用边长比**，不用角度，避免近正方形区域的退化。
- **`is_vertical` 必须在精修之后重算**，否则精修改了框、方向标记还是旧的。
- **不做无脑内收（tighten）**。卡内文字/花纹的梯度比卡边还强，一内收就会把卡边咬掉：
  20/20 会掉到 15/20。该功能默认关闭，`?tight=1` 才开。
- **大图先降到 ≤1800px** 再送模型，否则 WASM 侧内存吃不住。

## 已知限制

- **叠放的银行卡/社保卡靠两条阈值折叠**（满版高饱和占比 > 0.30、左侧人像暗像素 > 0.15）。
  只折叠不删除，被误判的可以一键救回。
- **人像面 180° 倒拍**会被人像位置判据误伤（人像跑到左侧），同样靠"救回"兜底。
  180° 判据本身没有可靠样本，至今未验证。
- **90° 侧躺的方向**取经验值（统一逆时针），不是算出来的。
- 两面配对目前按拍摄顺序，真正自动配对需要 OCR —— 国徽面只有签发机关和有效期，没有人名和号码。

## 隐私

- 图片**只在浏览器内存里处理**，没有任何上传、没有后端、没有埋点。
- 仓库内**不含任何真实证件样本**。测试图一律不入库。
- 若要自己积累基准集，请保持在本机，别提交。

## 目录

```
site/index.html          单文件应用（UI + 全部算法）
site/ml/                 模型与运行时（3.5 MB，可懒加载）
versions/v3..v5/         各版本快照 + md5 指纹 + 变更说明
```

历史版本说明写在各自 `VERSION.md` 里，含改动原因、实测数据、以及
**试过但不管用的方案**（避免后来者重新捡起死路）。
