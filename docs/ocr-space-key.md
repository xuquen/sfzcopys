# OCR.space 免费 Key 申请教程

给「保存文件名」里的 OCR 识别（姓名/证号/有效期止/地址）配一个免费 Key，大约 1 分钟。

> 为什么用 OCR.space：它是目前**少数允许网页直接调用**的 OCR 服务（接口开放了跨域许可），
> 而且免费额度对个人足够（每月 25000 次）。本工具只上传模板里用到的字段小条图，
> 整张身份证和人像照片不会离开你的手机。

## 申请步骤

1. **打开申请页**：<https://ocr.space/ocrapi/freekey>
2. **填邮箱**：页面上只有一个邮箱输入框，填一个常用邮箱，点 **GET API KEY**
   - 手机上直接用浏览器打开就行，不用翻墙不用注册账号
3. **收邮件**：几秒钟内会收到一封标题带 *OCR API Key* 的邮件，里面是一串 **K8 开头**的字符
   - 没收到的话翻一下垃圾邮件
4. **回到工具**：打开网页 → 点右上角齿轮进设置 → 把 Key 粘贴到「OCR.space Key」输入框 → 点别处即自动保存（Key 只存你手机本机）
5. 回到页面选项区，打开「联网 OCR」开关

## 常见问题

- **Key 换手机/清了浏览器数据就没了？** 是的，Key 只存本机 localStorage。邮件别删，或重新申请一个（免费的）。
- **想换 Key？** 在 ocr.space 邮件/账户里可以重置；重置后把新 Key 重新粘进设置即可。
- **识别错了？** 姓名/证号/地址/有效期在清晰照片上实测全对；拍糊了会识别不出，重拍即可。
- **不想联网？** 不开「联网 OCR」就行，工具其余功能全部纯本地。
