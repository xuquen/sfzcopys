它做什么

从一张歪斜、有阴影、偏色的照片，到一张能直接打印的证件复印件，中间的活全归它。

⌖自动找卡与转正神经网络角点检测（1.9MB ONNX-WASM 本地推理）+ 经典算法兜底，180° 倒拍、面别判反都能纠正。
◐自动白平衡亮部灰世界估计通道增益，偏蓝偏黄一拍就正；色相恒定，不会把国徽拉灰。
☀去阴影 / 白底增强平场校正抹掉不均匀光照；局部纸白归一化把底纹推纯白，人像彩色零改动。
▦A4 精确拼版300dpi 下 85.6×54mm 精确 1:1，整页贴图零重采样；正反面并排，间距 10mm。
⇩PDF / 图片 / 打印自托管 jsPDF 导出 A4 PDF，或存长边图片；打印走 @page A4，尺寸不走样。
✎文件名模板 + OCR{姓名}{证号}{有效期止}{地址}{时间}{序号} 自由组合；可选 OCR.space 联网识别，只上传字段小条图。
隐私是设计前提，不是附加选项：检测、校正、拼版、导出全部在浏览器本地完成，图片不上传。唯一联网项是可选的 OCR 命名，且只上传模板用到的字段小条图（如姓名那一行），整卡与人像照片不出设备。

为什么自己造这个轮子

身份证拼版软件不少，多数要么塞一堆依赖包、要么要装客户端。这个项目的取舍只有六条：

→体积小只依赖浏览器，不内置一堆依赖包；唯一的「轮廓包」（角点检测模型）仅 1.9MB，用不用都行。
→不挑设备手机拍照、电脑复制粘贴（截图 / 扫描件）同一条流程，什么设备拿起来就用。
→电脑微信零落盘电脑端微信截图进剪贴板后，从导入到导出全程在浏览器里完成，不用找地方建本地过程文件。
→OCR 命名（默认关）识别只上传字段碎片小图，服务器看不到全图；不开就是纯本地。
→手机微信导入（规划中）网页无权读微信聊天，小程序接口被卡——这条路在找办法，暂时靠电脑端微信。
→识别失败怎么办先提高素材质量：正对拍摄、光线均匀、避免反光，多数识别失败是图的问题不是工具的问题。

三步出片

导入手机拍照 / 相册 / 微信图 / 桌面扫描件，一次可以丢多张。
检查自动转正与拼版，不满意可手动旋转、删卡、开辅助线。
导出保存 PDF / 图片，或直接打印；文件名按模板自动生成。

技术要点

单文件 HTML：全部逻辑、样式、模型加载在一个 index.html 里，克隆即用，无构建。
本地推理：DocCornerNet 角点模型 1.9MB，onnxruntime-web WASM，无服务端。
像素管线：白平衡 → 平场去阴影 → 局部纸白漂白，四级顺序经过 20 张基准实测标定。
兼容性：现代浏览器；拍照入口走系统相机；HEIC/TIFF/PDF 会提前拦截并提示。
